# CSC API
![image](https://github.com/HKIBIMTechnical/Automation-2023-CSC-API/blob/main/image.png)

## Overview

Mechanical, Electrical and Plumbing (MEP) occupies a large portion of the building service system. As a contractor, China State Construction produces bundle of professional drawings for MEP installation, and there is a huge need for an efficient and automatic method to generate such drawings. Therefore, a rule-based automation tool was developed through Revit API for both Combined Services Drawing (CSD) and Combined Builder’s Work Drawing (CBWD), enabling greater automaton and saving up to 50 percent of time. This parametric and vendor-independent BIM approach also provides a deeper understanding of information interoperability and data exchange to empower automatic drawing generation.
